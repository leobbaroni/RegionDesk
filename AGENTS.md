# Repository workflow

- Work on the default branch, `main`, as explicitly requested by the owner. Do not create a feature branch or worktree unless the owner changes this instruction.
- Preserve unrelated local changes. Fetch before publishing, resolve upstream changes without force-pushing, and commit verified changes to `main`.
- Keep the beginner setup steps in README.md and Start Here.txt aligned with the setup scripts and browser UI. Android support was removed at the owner's request.
- Keep one current distributable and the stable app folder; use scripts/clean.ps1 for generated test data and superseded releases. Never clean saved profiles in AppData.
- Report measured routing and browser settings separately from TikTok account eligibility or fingerprint masking.
