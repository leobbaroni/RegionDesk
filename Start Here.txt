REGIONDESK - START HERE

1. Download RegionDesk-Setup.exe from the project's GitHub Releases page.
2. Double-click it. RegionDesk installs for your account and opens automatically.
   Next time, use the RegionDesk desktop icon or Start Menu shortcut.
   No ZIP extraction, Git or Node.js is needed.
3. In Profiles, give your account workspace a name and choose a region preset.
   Click Save profile. Advanced settings can usually stay closed.
4. In Connections, enter your proxy host, port, protocol and credentials.
   Click Save and connect. If the check fails, follow the message shown.
5. Open Browser. Enter an HTTPS address or choose TikTok.

EVERYDAY USE
- Select the same profile to keep its cookies and logins.
- Verify connection after reopening the app or switching profiles.
- Use + or Ctrl+T for a new tab, Ctrl+W to close, Ctrl+Shift+T to reopen.
- Use the star to bookmark a page. Bookmarks stay in the selected profile.
- Click a bookmark or saved shortcut to open it in a new tab.
- If one page fails, use Reload page or Go back. Other tabs stay connected.
- Use Find in page or Ctrl+F to search the current page.
- Pop out moves the browser into a separate window with the same tabs and session.
  Closing that window returns it to the workspace. F11 toggles full screen.
- Proxy setup and browser use happen here. BlueStacks/Android is no longer needed.

PRIVACY
Profiles have separate cookies and storage. Existing online accounts can retain
server-side history. A proxy does not guarantee US viewers or an undetectable
browser. Optional common-tracker blocking is in Profiles; turn it off if a site
breaks. It is a small starter rule set, not a full ad blocker.

UPDATES
Close the app and run the newest installer. Saved profiles and logins are kept.
Uninstall through Windows Settings > Apps > RegionDesk. Saved profiles remain.
Never delete %APPDATA%/RegionDesk if you want to keep your logins.

SOURCE DOWNLOADS
If you downloaded the source ZIP, extract all files and double-click
Start RegionDesk.bat. It handles setup, builds changed code and opens the app.

KEEPING THE PROJECT SMALL (SOURCE DOWNLOADS)
Clean Project.bat removes generated test data and superseded release copies.
It keeps dependencies, the current installer and the stable app folder.
Only run it when tests and packaged test apps are closed.
